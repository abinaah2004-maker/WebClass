## Recent additions

This repository now includes additional HTML fundamentals tasks, advanced CSS practice, ten DOM lessons, Week 5 conditional/loop exercises, Week 6 API examples, a BookFinder project, form-validation exercises, and an accessibility audit worksheet.

## Notes

- Some Week 6 and Week 7 exercises use public APIs and require an internet connection.
- The BookFinder reading list is stored in the current browser using localStorage.
- The accessibility report is a worksheet. It does not claim a formal audit or WCAG conformance.
- The pages should be opened and tested in a browser before coursework submission.
