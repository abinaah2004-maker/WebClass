Use Korean to live confidently in Korea.

This is not a beginner phrase list. Practise explaining problems, negotiating politely, asking follow-up questions, understanding notices and giving reasons. The dialogues use intermediate grammar and natural polite speech. TOPIK level is a target, not an official certification.

1. Intermediate grammar toolkit

Learn these patterns as tools for explaining yourself naturally. Notice the nuance, not only the English translation.

2. Real-life conversation training

Each scene has 20 spoken lines. Read the Korean first, try to understand it, then reveal the meaning. Read both roles aloud to practise fluency.

Active speaking challenge

3. TOPIK-style understanding check

In the restaurant scene, why does the student ask to change the shift?

4. Your weekly output task

Write a short message (5–7 Korean sentences) to a manager explaining a scheduling problem and suggesting a solution. Include:

  • the reason using -기 때문에 or -(으)ㄴ/는 바람에
  • a polite request using -(으)ㄹ 수 있을까요?
  • an alternative using 대신에 or 는 어떨까요?
  • a closing sentence showing consideration.
How to study this properly: Day 1 read and shadow the 20 lines. Day 2 cover English and translate aloud. Day 3 role-play both people without reading. Day 4 write your own version using the grammar. Day 5 review mistakes and repeat.
