Week 9.1: Accessibility audit

Abinash Lamichhane · Computer Engineering

Use this checklist to review the accessibility of your coursework pages. A manual checklist is not a substitute for testing with real users or assistive technology.

Audit checklist

Manual testing steps

  1. Navigate without a mouse using Tab, Shift+Tab, Enter, and Space.
  2. Zoom to 200% and inspect page layout.
  3. Check text contrast and image alternative text.
  4. Test form errors and dynamic status messages.
  5. Fix issues, then repeat the audit.
