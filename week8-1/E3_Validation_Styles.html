EXERCISE 03 / CSS STATES

See validation in action.

Type into each field. Once a non-empty value is valid, its border turns green. Invalid non-empty values get a red border.

Use letters, numbers, or underscores only.

Accessibility note: colour is a visual hint, not the only validation method. The browser still checks the actual rules and provides its validation messages.
Concepts: :valid · :invalid · :focus-visible · native constraint validation
