EXERCISE 02 / HTML VALIDATION

Let the browser help.

Submit the form with empty or incorrect values to see the browser's built-in validation messages.

Try this: enter an invalid email, age 15, or a URL without https://. Notice how the browser blocks submission until the required values are valid.
Concepts: required · type · minlength · maxlength · min · max
