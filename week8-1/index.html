WEB PROGRAMMING / WEEK 08

Forms that work for everyone.

Practise semantic HTML forms, built-in validation, accessible labels, and useful feedback. Each activity is a separate hands-on exercise.

Exercises & homework

  • 01 · Sign-in formLabels, email and password fields, required input.
  • 02 · Validation attributesTry required, minlength, pattern, min and max.
  • 03 · Validation stylesSee valid and invalid states while you type.
  • 04 · Contact formBuild a message with accessible, native validation.
  • 05 · Student registrationGroup fields, validate a student ID and explore a range input.
Practice safely: These are front-end learning demos. They do not create accounts, send messages, or save the information you enter. Use sample data only.
