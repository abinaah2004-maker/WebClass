# Week 12 · React State and useState

**Student:** Abinash Lamichhane · **ID:** 202637724

This page practises React state through six interactive exercises:

1. **Tech Desk Builder** — filter equipment, add products, change quantities, apply starter setups and compare the total with a spending budget.
2. **Counter & History** — update a counter, review recent values and undo.
3. **Two-player Scoreboard** — update two scores independently and reset them.
4. **Live Word Count** — edit text and see the word and character totals update.
5. **React Quick Tips** — reveal short reminders about state and component updates.
6. **Study Queue** — add tasks, mark them complete and remove finished items.

The page uses React `useState` for interactive values. The visual layout and styling are custom to this coursework page.
