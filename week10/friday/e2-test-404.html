4. What I learned

  • A 404 status tells the visitor that the requested resource was not found.
  • A custom 404 page should explain the problem in plain language.
  • Useful recovery links help visitors continue instead of leaving the website.
  • The root-level 404.html is used by GitHub Pages for missing pages in this site.
