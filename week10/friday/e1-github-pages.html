FRIDAY / DEPLOYMENT

E1 — GitHub Pages.

GitHub Pages publishes static HTML, CSS and JavaScript files from a repository so that a website can be opened through a public URL.

1. Open repository settings

On GitHub, open the repository and select Settings → Pages.

2. Choose the deployment source

Under Build and deployment, choose Deploy from a branch. Select the main branch and the /(root) folder, then save.

3. Wait for deployment

Open the Actions tab or the Pages settings area and wait for the deployment workflow to finish. GitHub displays the published site URL when it is ready.

4. Test the website

Open the URL in a private/incognito window or another browser. Check that images, stylesheets and navigation links load correctly.

Evidence to capture: the Pages source setting, a successful deployment status and the live website. This guide does not claim that settings have been changed or a new deployment verified.
