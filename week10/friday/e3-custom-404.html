E3 — Custom 404 page.

I create a dedicated not-found page that explains the problem in plain language and provides a clear route back to the main website.

How it works

GitHub Pages looks for a file named 404.html at the publishing source root. This repository now has a custom root-level page for the WebClass site.

Design decisions

  • Use a clear “Page not found” heading.
  • Explain that the link may be incorrect or the page may have moved.
  • Provide a prominent link to the WebClass homepage and the Week 10 hub.
  • Keep the page responsive and usable with a keyboard.

Preview the custom 404 page ↗

After deployment, test a made-up route and capture the result. The preview link above opens the custom page directly; the real not-found behavior should be checked using a nonexistent URL.
