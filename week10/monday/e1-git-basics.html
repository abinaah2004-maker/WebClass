MONDAY / VERSION CONTROL

E1 — Git repository.

In this exercise I practice creating a local Git repository, tracking files and reviewing the commit history.

1. Open the project folder

Open the folder you want to track in VS Code, then open its integrated terminal.

2. Initialize Git

git init

This creates a hidden .git directory and starts version control in the current folder.

3. Stage and commit

git status
git add .
git commit -m "Initial commit"

Staging selects the changes for the next snapshot. A commit saves that snapshot with a message.

4. Read the history

git log --oneline

This shows a compact list of commits. Use git status again to check whether there are uncommitted changes.

Evidence to capture: terminal showing the initialization, successful commit and one-line commit history. Run these commands locally before adding your screenshot.
