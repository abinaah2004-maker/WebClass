MONDAY / REMOTE REPOSITORY

E3 — Push to GitHub.

I connect the local repository to a GitHub repository so that the committed work is stored remotely.

1. Create an empty GitHub repository

On GitHub, create a new repository. If you already have the local project, avoid initializing the remote with a README to keep the first push simple.

2. Set the remote

Replace the example URL with the HTTPS URL of your own repository.

git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git

3. Ensure the branch is main

git branch -M main

4. Push the commit

git push -u origin main

5. Verify on GitHub

Refresh the repository page and check that your files and commit appear. For later updates, use git add ., git commit -m "Describe change" and git push.

Evidence to capture: the successful push in the terminal and the matching files/commit on your GitHub repository page. Never paste a password or personal access token into a screenshot.
