MONDAY / COLLABORATION

E2 — Branch & merge.

Branches let me work on a feature separately from the main version, then combine the finished work.

1. Create a feature branch

git switch -c feature-style

2. Make a small change

For example, add a new CSS rule or a small section to your practice page. Save the file.

3. Commit the feature

git status
git add .
git commit -m "Add feature styling"

4. Return to main and merge

git switch main
git merge feature-style

5. Check the result

git log --oneline --graph --all

The graph helps show how the feature branch was merged. If Git reports a conflict, open the marked file, choose the intended final content, save it, stage it and complete the merge commit.

Evidence to capture: the branch creation, feature commit and merge shown in the terminal. Do not claim a merge until it has completed successfully.
