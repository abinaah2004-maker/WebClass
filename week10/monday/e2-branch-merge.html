MONDAY / EXERCISE 02

Branch & merge.

A branch lets me develop a change without disturbing the main version. In this example, I add a CSS file on a feature branch, then merge it into main. Compare the two browser previews to see the visible change.

BEFORE / MAIN BRANCH

Original HTML page

Hello Git

I am learning how Git branches keep changes separate.

AFTER / FEATURE-STYLE MERGED

Page after adding CSS

Hello Git

I am learning how Git branches keep changes separate.

The feature branch adds a CSS rule to change the font and page appearance.

FEATURE FILE / style.css

The code that creates the visible change

body {
  font-family: Arial, sans-serif;
  background: #eef4ed;
  color: #24392c;
}
h1 {
  color: #1d603c;
}

The right-hand preview represents the result after the CSS file is added and the branch is merged. The preview is an illustration of the expected result; your Git history must come from your own terminal and GitHub repository.
