1. Problem and purpose

The accessibility task checks whether keyboard users can bypass repeated navigation and reach the main content directly. The skip link should be the first keyboard stop, become visible when focused, and move focus to a meaningful main-content target when activated.

3. Keyboard test procedure

  1. Open a deployed page in Chrome and reload it without clicking anywhere.
  2. Press Tab once. Check whether “Skip to the main content” becomes visible and receives focus.
  3. Press Enter to activate the skip link.
  4. Check whether the main content receives focus. Press Tab again to confirm that focus continues from the main content rather than returning through the page navigation.
  5. Repeat the same test for each page listed in the verification table.

Important: Tab moves keyboard focus; Enter activates the focused link. Tab should not automatically activate the skip link.
