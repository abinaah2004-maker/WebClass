1. Purpose

A skip link helps keyboard users bypass repeated navigation and move directly to the main content. It should be the first keyboard-focusable control, become visible when focused and move focus to a meaningful main-content target when activated.

3. Test procedure

  1. Open the deployed page and reload it without clicking anywhere.
  2. Press Tab once and check whether the skip link receives focus and becomes visible.
  3. Press Enter to activate the link.
  4. Check whether focus moves to the main content, then press Tab to continue through the page.
  5. Repeat on the Week 10 hub, portfolio and selected exercise/project pages.

Tab moves focus between controls. Enter activates the focused link. The expected behavior is not that Tab itself activates the skip link.

6. Reflection

Keyboard testing helps identify navigation barriers that may not be obvious when using a mouse. A clear focus indicator and a working skip link make a page easier to navigate for keyboard users and people who use assistive technologies.
