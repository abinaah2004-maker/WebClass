# Week 8 — JavaScript Form Validation

**Student:** Abinash Lamichhane  
**Course:** Web Programming  
**Topic:** Form validation and accessible feedback

## Exercises
- **E1 — Username:** required value and minimum three-character check on submit.
- **E2 — Email:** live format feedback while typing and validation on submit.
- **E3 — Password confirmation:** minimum length and matching-value checks.
- **Homework — Student registration:** validates full name, student ID, email, password, confirmation, program selection, and consent.

## Run locally
Open `index.html` in a browser, or open this folder in VS Code and use Live Server. Test invalid values first, then correct them.

## Files
- `index.html` — page structure and forms
- `styles.css` — responsive styling and focus states
- `script.js` — client-side validation

This is a front-end demo only. Registration information is not transmitted or stored. Real applications must also validate data on the server.
