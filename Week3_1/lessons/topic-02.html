Three ways to add CSS

CSS can be added inline, in a style element, or through an external stylesheet.

Example

<p style="color:teal">Inline style</p>
<style>p.internal{color:purple}</style>
<p class="internal">Internal style</p>
<link rel="stylesheet" href="style.css"> <!-- external stylesheet -->

Try it

Open this page in your browser, change a declaration in the example, and compare the result in your own HTML file.
