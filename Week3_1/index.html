6. Responsive design checklist

  • Use a viewport meta tag.
  • Use flexible widths instead of fixed page widths.
  • Use grid or flexbox for layouts that can wrap.
  • Test narrow screens and keyboard navigation.
  • Respect reduced-motion preferences.
