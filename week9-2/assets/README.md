# Week 9.2 image assets

Place your four optimized image exports in this folder:

- `photo-400.jpg`
- `photo-800.jpg`
- `photo-400.webp`
- `photo-800.webp`

Create them from one real photograph you have permission to use. Keep the same subject and aspect ratio across the four exports. Use Squoosh or another image editor to resize and export JPEG and WebP versions. Record the actual byte sizes from the saved files; do not invent compression results.

The current E2 demonstration uses a credited Wikimedia Commons photograph directly. The local variants above are the next step needed for a fully self-contained JPEG/WebP comparison.
