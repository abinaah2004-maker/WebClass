EXERCISE 03 · SCRIPT LOADING

defer and async

Both attributes let the browser download an external script without pausing HTML parsing. They differ in when and in what order the scripts execute.

Live execution demonstration

The app waits until the DOM is ready. The independent analytics task runs when its download finishes; its order is not guaranteed. This local simulation uses timers to make the concept visible and does not send analytics data.

Correct code structure

<head>
  <script src="app-script.js" defer></script>
  <script src="analytics.js" async></script>
</head>
  • defer: downloads in parallel, then executes after HTML parsing; deferred scripts preserve document order.
  • async: downloads in parallel and executes as soon as ready; execution order is not guaranteed.
  • Important: defer and async are intended for external scripts. They do not defer ordinary inline classic scripts.
