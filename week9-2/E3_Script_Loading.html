Understanding defer and async

External JavaScript can be downloaded while the browser parses HTML. The script attributes control when the browser executes each file.

Compare the three loading methods

Normal

Parser-blocking

<script src="app.js">

The browser pauses HTML parsing while it fetches and executes a classic script.

defer

After HTML parsing

<script src="app.js" defer>

The file downloads during parsing, then runs after parsing finishes. Deferred scripts keep document order.

async

As soon as ready

<script src="analytics.js" async>

The file downloads independently and runs as soon as it is ready. Its execution order is not guaranteed.

Code used in this page

<head>
  <script defer src="E3_app.js"></script>
  <script async src="E3_analytics.js"></script>
</head>
  • defer and async apply to external scripts; adding them to a normal inline classic script does not defer its execution.
  • Use defer for scripts that depend on the parsed page or need to preserve order.
  • Use async for independent scripts that do not rely on another script's execution order.
