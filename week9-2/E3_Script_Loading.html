Compare the three loading methods

Normal

Parser-blocking

<script src="app.js">

The browser pauses HTML parsing while it fetches and executes a classic script.

defer

After HTML parsing

<script src="app.js" defer>

The file downloads during parsing, then runs after parsing finishes. Deferred scripts preserve document order.

async

As soon as ready

<script src="analytics.js" async>

The file downloads independently and executes as soon as it is ready. Its order relative to other scripts is not guaranteed.

Code used in this exercise

<head>
  <script src="E3_app.js" defer></script>
  <script src="E3_analytics.js" async></script>
</head>

What each file does

  • E3_app.js: waits until the parsed page is available, updates the status fields, records events, and attaches the test and clear button actions.
  • E3_analytics.js: runs independently, records a local timestamp, and notifies the app. It does not collect or send personal data.

Important: defer and async affect external scripts. Adding either attribute to a normal inline classic script does not delay that inline script.

Use defer when a script needs the parsed HTML or must preserve order. Use async for independent scripts that do not rely on another script's execution order.
