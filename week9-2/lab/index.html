What changes in each stage?

01 · Semantic HTML

Meaningful header, navigation, main, section, article and footer landmarks.

02 · Buttons and descriptive links

Real keyboard-operable controls replace clickable-looking divs.

03 · Image alternatives

Content images receive useful descriptions; decorative images use empty alt text.

04 · Color contrast

Text and controls use stronger contrast, targeting at least 4.5:1 for normal text.

05 · Form labels and errors

Visible labels, connected error messages and focus on the first invalid field.

06 · Image loading and layout stability

Intrinsic dimensions reserve space; below-the-fold images load lazily.

07 · Deferred scripts

Scripts use defer so HTML parsing is not blocked and deferred execution order is preserved.
