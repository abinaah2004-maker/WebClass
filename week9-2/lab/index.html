Step 1 · Semantic HTML

Replace generic page containers with meaningful landmarks such as header, navigation, main, sections, articles and footer. A skip link helps keyboard users jump to the main content.

<header>…<nav aria-label="Main navigation">…</nav></header>
<main id="main">
  <section>…<article>…</article></section>
</main>
<footer>…</footer>

Step 2 · Buttons and descriptive links

Replace clickable-looking elements with real buttons and links. Buttons can be activated by keyboard, and their expanded state communicates whether movie details are open.

<button type="button" aria-expanded="false"
  aria-controls="detail-1">View Details</button>

Open completed step 2

Step 3 · Image alternatives

Informative movie images receive meaningful alternative text. A decorative featured image uses an empty alt attribute so screen readers can skip it.

<img src="movie.jpg"
  alt="Placeholder movie artwork for The Last Harbor">
<img src="decoration.jpg" alt="">

Open completed step 3

Step 4 · Color contrast

Improve text and control colors so content is readable against its background. Check normal text against the WCAG AA 4.5:1 target, and verify focus indicators separately.

body {
  background: #090b12;
  color: #f5f7fb;
}
a { color: #ff7881; }

Open completed step 4

Step 5 · Form labels and errors

Give every form field a visible label. Connect its error message using aria-describedby, set aria-invalid when validation fails, and move focus to the first invalid field.

<label for="subscriber-email">Email address</label>
<input id="subscriber-email" type="email" required
  aria-describedby="subscriber-email-error">
<p id="subscriber-email-error" class="error"></p>

Open completed step 5

Step 6 · Image loading and layout stability

Set intrinsic image dimensions to reserve space before images load. Keep initially visible images eager and lazy-load images farther down the page where appropriate.

<img src="movie.jpg" alt="Movie artwork"
  width="400" height="500"
  loading="lazy" decoding="async">

Open completed step 6

Step 7 · Deferred scripts

Load the external application script with defer. The browser can parse the HTML while downloading the file, then executes the deferred script after parsing has finished.

<!-- At the end of body -->
<script src="lab.js" defer></script>
