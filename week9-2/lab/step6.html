Image loading and layout stability

Set intrinsic width and height to reserve space before images load. Use lazy loading for images below the fold; keep likely above-the-fold images eager.

Example

<img src="photo.jpg" alt="…"
 width="400" height="500"
 loading="lazy" decoding="async">
