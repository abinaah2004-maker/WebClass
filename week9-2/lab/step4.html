Color contrast

The starter uses pale gray text on light backgrounds. Choose foreground and background colors with sufficient contrast. WCAG AA generally requires 4.5:1 for normal text and 3:1 for large text.

Example

.movie-meta { color: #4b5563; }
.footer { background: #172033; color: #e5e7eb; }
a:focus-visible, button:focus-visible {
  outline: 3px solid #f59e0b;
}
