How to run your own Lighthouse audit

  1. Open the page you want to test in Chrome or Microsoft Edge.
  2. Open DevTools with F12 or right-click and choose Inspect.
  3. Open the Lighthouse panel. Select the categories required by the assignment.
  4. Choose the same device mode and throttling settings for both runs.
  5. Run the audit and save a screenshot showing the page URL and scores.
  6. Fix one or more specific issues, reload the page, and run the audit again with the same settings.
  7. Save the second screenshot and explain what changed. Do not claim a fix unless the code and new result support it.

Common performance improvements

  • Use appropriately sized responsive images with srcset and sizes.
  • Set image width and height to reserve layout space.
  • Lazy-load images below the initial viewport; do not lazy-load the main hero image when it is the LCP image.
  • Use defer for application scripts that need the parsed document.
  • Remove unused scripts and styles only after confirming they are not needed.
  • Check the Lighthouse diagnostics instead of guessing which change caused a score improvement.
<img
  src="photo-960.jpg"
  srcset="photo-480.jpg 480w, photo-960.jpg 960w"
  sizes="(max-width: 600px) 100vw, 800px"
  alt="Describe the photograph"
  width="960"
  height="640"
  loading="lazy"
  decoding="async">

Check your understanding

Why should the before and after Lighthouse runs use the same viewport and throttling settings?

Using the same settings makes the comparison fairer. Otherwise, score differences may come from the test environment rather than the code changes.
