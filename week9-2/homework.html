What changed

AreaImprovement in the solution
Structure and navigationSemantic landmarks, a skip link, a main-content target and visible keyboard focus.
Interactive controlsReal buttons, working movie details, search behavior and announced result status.
Image alternativesDescriptive alternative text for informative images and empty alt text for decorative imagery.
Contrast and layoutClearer text contrast, focus styles and responsive card layout.
FormsAssociated labels, validation feedback, error descriptions and focus management.
Image performanceIntrinsic dimensions, deliberate eager/lazy loading and asynchronous decoding.
Script loadingExternal application JavaScript loaded with defer.

How to review the work

  1. Open the original starter and note the inaccessible controls and layout issues.
  2. Open the completed solution and test the search, movie-detail buttons and newsletter form.
  3. Use Tab and Shift+Tab to move through links, buttons and form fields.
  4. Compare the recorded audit scores above with the original report evidence.
  5. Run a fresh Lighthouse audit on the current solution if you have changed it since the supplied screenshots.

Important: A Lighthouse score of 100 does not prove full WCAG conformance. Do not mark keyboard or screen-reader checks as passed unless you have actually performed them.
