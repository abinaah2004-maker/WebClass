1. What the audit is checking

Lighthouse Performance estimates how quickly the page displays useful content and becomes responsive. Important signals include Largest Contentful Paint (LCP), Total Blocking Time (TBT), and Cumulative Layout Shift (CLS).

LCPLargest Contentful Paint
TBTTotal Blocking Time
CLSCumulative Layout Shift

2. Problems to investigate

  • Render-blocking CSS can delay the first useful render.
  • Long JavaScript tasks can delay interaction.
  • Unnecessary or oversized assets increase transfer and rendering time.
  • Missing or weak cache headers can cause repeat visits to download assets again.

Use the exact warnings shown in your own Lighthouse report. The items above are common checks, not a claim that every issue was present in the latest run.
