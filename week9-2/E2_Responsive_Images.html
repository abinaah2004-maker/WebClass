WEEK 9.2 · EXERCISE 02

Responsive images

One photograph can be saved at different widths. The browser does not need to download the largest file every time: it can choose an image that suits the space available on the page and the screen resolution.

Try the image

Resize this page or open it on your phone. The photograph keeps the same shape, but the browser can select the 400-pixel or 800-pixel version. The image is a real photograph from Unsplash, not generated artwork.

Select the button to see the image file and its dimensions.

What the HTML does

srcset lists available image widths. sizes tells the browser how wide the image is expected to appear in the layout. The browser uses that information, along with the device pixel ratio, to choose a suitable file.

<img
  src="photo-800.jpg"
  srcset="photo-400.jpg 400w,
          photo-800.jpg 800w"
  sizes="(max-width: 700px) 100vw, 800px"
  width="800"
  height="400"
  alt="A yellow tram on a Lisbon street">

The picture element above also offers WebP. If the browser supports WebP it can use that source; otherwise it falls back to the JPEG in img.

The width and height attributes reserve space before the photo loads. This helps prevent the page from jumping while the image appears.

Check it yourself

  1. Open this page in a wide browser window and press the button.
  2. Make the window narrow or open the page on your phone, then press the button again.
  3. Open Developer Tools → Network → Img and reload the page to see which image request was made.
  4. Compare the selected file and its dimensions. The browser may choose differently depending on the screen and device pixel ratio.

For images further down a long page, add loading="lazy". Do not lazy-load the main image at the top if it is likely to be visible as soon as the page opens.

What I learned

A responsive image is not just an image that shrinks with CSS. The browser can also download a smaller file when a smaller version is enough. This saves data on smaller screens while keeping a larger option available when it is needed.
