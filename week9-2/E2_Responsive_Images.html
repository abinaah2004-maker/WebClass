EXERCISE 02 · IMAGE OPTIMIZATION

Responsive Web images

A responsive image lets the browser select an appropriate resource for the available layout and screen density. The picture element can also offer modern formats with a fallback.

Working responsive illustration

Mobile: compact sourceDesktop: wide sourceFallback: img element

Resize the browser window to test the media condition.

Code pattern for WebP with JPEG fallback

In a real project, create matching image files at 400 × 200 and 800 × 400. The browser checks supported formats and chooses a suitable width using srcset and sizes.

<picture>
  <source type="image/webp"
    srcset="photo-400.webp 400w, photo-800.webp 800w"
    sizes="(max-width: 650px) calc(100vw - 36px), 800px">
  <img
    src="photo-800.jpg"
    srcset="photo-400.jpg 400w, photo-800.jpg 800w"
    sizes="(max-width: 650px) calc(100vw - 36px), 800px"
    alt="Describe the photograph"
    width="800" height="400">
</picture>

Why width and height? They reserve the image's aspect ratio before download and help prevent layout shifts. The JPEG img remains the fallback when the browser cannot use the WebP source.
