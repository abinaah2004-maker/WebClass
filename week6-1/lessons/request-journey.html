The request journey

Follow the main stages from the browser to an API and back.

  1. Browser event: user clicks a button.
  2. JavaScript builds a request URL.
  3. fetch sends an HTTP request over the network.
  4. The API server processes the request and returns a status and body.
  5. JavaScript checks the response and parses JSON.
  6. The page renders the result or displays an error.

Start with stage 1.
